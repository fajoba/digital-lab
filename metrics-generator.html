Build the two real-data CSVs

This tool calculates scores from public source data instead of inventing city rankings. Run each section, download its CSV, and add it to your Digital Lab project. Both datasets cover the exact 100 metros in the game.

1 · Good-weather days

10 years of daily weather

Uses Open-Meteo's ERA5-Land reanalysis for 2015–2024 at one representative city per metro. A good day has a high of 60–85°F, less than 0.254 mm (0.01") precipitation, and at least 2 hours of sunshine. The reported score is the 10-year annual average.

Weather is a representative-city proxy, not the average across the entire metro. This matters for large/coastal/mountainous metros. The site should disclose this limitation.

0/100 metro weather records ready

Open-Meteo offers no-key access for noncommercial use; results are cached in your browser so you can retry incomplete requests. These calculations require an internet connection.

2 · Metro walkability

EPA index · 1–20

Uses the U.S. EPA Smart Location Database (2021). The algorithm groups census block groups by their historic metro CBSA and computes a population-weighted average of NatWalkInd, using TotPop as the weight.

One-time source download: Download the official EPA CSV (large file), then choose it below.

This is not Walk Score®. EPA's index is based on street-network connectivity, land-use mix, and proximity to transit, and reflects older neighborhood data.

3 · Publish the generated data

  1. Download city-good-weather-days.csv and city-walkability.csv using the buttons above.
  2. Move both files into your digital-lab folder alongside city-game.html.
  3. Commit and push the two files with GitHub Desktop. Netlify will publish them, and the latest City Eliminator code will load them automatically for everyone.

If an EPA metropolitan area name has changed since 2021, the tool will report an unmatched metro rather than assign the wrong score. See the log for details.
